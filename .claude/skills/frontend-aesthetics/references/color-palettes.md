## Palette Generation Strategies

### Strategy 1: Start with a Dominant Color

1. Choose your dominant color (60% of palette)
2. Add a sharp accent (10% - high contrast)
3. Fill neutrals (30% - grays/supporting colors)

```css
/* Example: Dominant Blue */
--dominant: #0A2E4D; /* 60% - backgrounds, large areas */
--accent: #FF6B35;   /* 10% - CTAs, highlights */
--neutral-1: #E8EEF2; /* 30% - text, borders */
--neutral-2: #B8C5D0;
--neutral-3: #7A8A99;
```

## Color Contrast Guidelines

### WCAG AA Compliance

**Normal Text (< 18pt):**
- Minimum contrast ratio: 4.5:1

**Large Text (≥ 18pt or ≥ 14pt bold):**
- Minimum contrast ratio: 3:1

**UI Components:**
- Minimum contrast ratio: 3:1

### Testing Contrast

Use this tool: https://webaim.org/resources/contrastchecker/

Or calculate manually:
```javascript
function getContrastRatio(color1, color2) {
  const l1 = getLuminance(color1);
  const l2 = getLuminance(color2);
  const lighter = Math.max(l1, l2);
  const darker = Math.min(l1, l2);
  return (lighter + 0.05) / (darker + 0.05);
}
```

## Common Mistakes

### ❌ Mistake 1: Even Distribution
```css
/* Bad - No clear hierarchy */
--color-1: #FF6B6B; /* 25% */
--color-2: #4ECDC4; /* 25% */
--color-3: #45B7D1; /* 25% */
--color-4: #FFA07A; /* 25% */
```

### ✅ Fix: Dominant + Accent
```css
/* Good - Clear hierarchy */
--dominant: #1A1A1A; /* 60% */
--accent: #FF6B6B;   /* 10% */
--neutral-1: #F5F5F5; /* 20% */
--neutral-2: #A0A0A0; /* 10% */
```

### ❌ Mistake 2: Purple Gradient Cliché
```css
/* Seen everywhere */
background: linear-gradient(135deg, #8B5CF6 0%, #EC4899 100%);
```

### ✅ Fix: Unexpected Gradient
```css
/* Distinctive */
background: linear-gradient(135deg, #0A2E4D 0%, #00D9FF 100%);
/* Or avoid gradients entirely */
```

### ❌ Mistake 3: Low Contrast Pastels
```css
/* Fails WCAG */
--bg: #F5F5F5;
--text: #CCCCCC; /* 1.6:1 contrast - too low */
```

### ✅ Fix: High Contrast Text
```css
/* Passes WCAG AA */
--bg: #F5F5F5;
--text: #2A2A2A; /* 10.9:1 contrast */
```

## Exporting Your Palette

Once you've designed your palette, export it as CSS variables:

```css
/* colors.css */
:root {
  /* Brand */
  --brand-primary: #yourcolor;
  --brand-secondary: #yourcolor;

  /* Backgrounds */
  --bg-base: #yourcolor;
  --bg-elevated: #yourcolor;
  --bg-overlay: #yourcolor;

  /* Text */
  --text-primary: #yourcolor;
  --text-secondary: #yourcolor;
  --text-tertiary: #yourcolor;

  /* Accents */
  --accent: #yourcolor;
  --accent-hover: #yourcolor;

  /* Semantic */
  --success: #yourcolor;
  --warning: #yourcolor;
  --error: #yourcolor;
  --info: #yourcolor;

  /* Borders */
  --border: #yourcolor;
  --border-subtle: #yourcolor;
}

/* Optional: Dark mode override */
@media (prefers-color-scheme: dark) {
  :root {
    /* Override colors here */
  }
}
```

Remember: **Commit to an aesthetic. Dominant colors with sharp accents always outperform timid, evenly-distributed palettes.**
